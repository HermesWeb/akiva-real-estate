# Akiva.co Real Estate Platform

A premium, responsive frontend interface for a modern real estate enterprise based in Lagos. Built to showcase structural precision and editorial design.

## Tech Stack
* **HTML5** for semantic structure
* **Tailwind CSS** for responsive, utility-first styling
* **Vanilla JavaScript** for IntersectionObserver scroll animations
* **Netlify Forms** for backend lead capture

## Features
* Custom scroll-triggered fade-up animations
* Fully responsive mobile and tablet views
* Form-to-email routing for property sourcing
